# Projects Hardware

A curated collection of walkthroughs, notes, and project documentation focused on homelab builds, device setups, networking labs, operating system migrations, and practical IT experimentation.

## Overview

This repository contains hands-on documentation for a range of personal technology projects, including:

- Home lab environments and infrastructure experiments
- Network lab and switching notes
- Device and hardware walkthroughs
- Operating system setup and migration guides
- Portable security and troubleshooting tooling

The goal is to provide a structured reference for practical builds, configurations, and lessons learned while working with hardware and systems in a self-hosted environment.
